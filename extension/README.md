# Mindrawer のブラウザ拡張（Chrome・Edge）

読んでいるページで右クリックすると「Mindrawer にしまう」が出ます。選んだ文・ページ・リンクを、Web 版の Mindrawer に送ってしまいます。ツールバーのボタンからは、ひとこと書き足してしまえます。

## 入れ方（ストアに出すまで）

1. このフォルダ（`extension/`）をパソコンに置く（GitHub の「Code」→「Download ZIP」で取ってきて展開）
2. Chrome なら `chrome://extensions`、Edge なら `edge://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

メモは Web 版（https://yusuke827827.github.io/hikidashi/）のブラウザの中に入ります。開く場所は拡張機能の「オプション」で変えられます。
